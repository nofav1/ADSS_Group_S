# ADSS_Group_S :
## Worker module of supermarket system. 
#### All the data saved by SQLite database locally.
____

### Functions:
* Create new workers.
* Delete existing workers.
* Arrangements created automatically for 6 days a week(Sunday-Friday), by Israel timezone.
* Client can choose the LAST_DAY of a week for workers to submit their weekly constraints. ( Through configuration.yaml file )
* Workers can submit constraints to next week arrangement.
* Managers can create/manage/modify an arrangement by determining which worker will work, and when.
* Create new roles for workers by need.
